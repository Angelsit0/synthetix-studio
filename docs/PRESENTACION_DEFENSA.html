¿Qué es Synthetix Studio?

Un editor de código en la terminal que crea, edita, valida y analiza archivos usando comandos de texto.

📚 Pila y Validación de Sintaxis

Luis Orellana — LIFO: último en entrar, primero en salir

Stack (Pila)

[ ) ] ← tope [ { ] [ ( ]
  • push, pop, peek → O(1)
  • Hecha con nodos enlazados
  • pop y peek lanzan IndexError si está vacía

SyntaxChecker

  • Recorre el código carácter por carácter
  • Apertura ((, {, [) → apilar con línea y columna
  • Cierre (), }, ]) → sacar tope y comparar
  • ¿No coinciden? → error con posición exacta
  • ¿Pila no vacía al final? → apertura sin cerrar
  • Ignora strings y comentarios

O(n) una sola pasada

↩️ Undo / Redo — Patrón Memento

Luis Orellana — Dos pilas para viajar en el tiempo

UNDO: [estado1] → [estado2] → [estado3] ← tope REDO: [vacía] Al hacer UNDO: estado actual → pila Redo tope de Undo → estado actual Al hacer REDO: estado actual → pila Undo tope de Redo → estado actual Al editar: estado anterior → pila Undo pila Redo → SE VACÍA

¿Por qué una edición nueva vacía Redo?
Porque si deshiciste 3 cambios y luego haces algo nuevo, la "línea temporal" cambió — ya no tiene sentido rehacer los cambios viejos.

📊 MergeSort vs ShellSort

Luis Orellana — Patrón Strategy: se elige en tiempo de ejecución

MergeSort

Divide → ordena cada mitad → mezcla

TiempoO(n log n) siempre
MemoriaO(n) extra
EstableSí

Mantiene el orden original de elementos iguales. Ideal cuando importa el orden secundario.

ShellSort

Inserción mejorada con gaps de Knuth (1, 4, 13, 40...)

TiempoO(n^1.5) peor
MemoriaO(1) in-place
EstableNo

Ordena sin crear listas temporales. Compara elementos lejanos y los va acercando.

🏦 Cola FIFO

Alfredo Aureliano — Primero en llegar, primero en ser atendido

FRENTE → [solicitud #1] → [solicitud #2] → [solicitud #3] ← FONDO (la próxima (espera) (la última en atenderse) que llegó)
OperaciónQué haceComplejidad
enqueuePonerse en la fila (al fondo)O(1)
dequeueAtender al primero (sale del frente)O(1)

Hecha con nodos enlazados, con punteros _front y _back. Sin usar list, deque ni el módulo queue de Python.

⚡ Productor — Consumidor

¿Por qué un solo hilo?

Si mandamos muchas peticiones a la vez, la IA nos bloquea (error 429). Con un solo hilo, salen de a una, en orden FIFO.

¿Por qué se suelta el lock?

La IA tarda segundos. Si el hilo mantuviera el lock, queue-status y analyze quedarían congelados. El lock solo protege los datos, nunca la red.
